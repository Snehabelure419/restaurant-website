# 🍽️ Restaurant Website

### A Modern, Responsive & Elegant Restaurant Website

A beautifully designed, responsive restaurant website built using **HTML5 and CSS3**. It showcases an attractive hero section, delicious menu items, a food gallery, customer reviews, chef profiles, and a contact form — delivering a smooth browsing experience across desktop, tablet, and mobile devices.

## ✨ Features

- 📱 **Responsive Design** — Adapts to different screen sizes.
- 📌 **Fixed Navigation Bar** — Provides convenient navigation.
- 🍴 **Hero Section** — Welcomes visitors with an attractive restaurant introduction.
- 🍕 **Interactive Menu Cards** — Presents food items in a visually appealing layout.
- 🖼️ **Food Gallery** — Showcases restaurant dishes and food photography.
- ⭐ **Customer Reviews** — Displays customer feedback and testimonials.
- 👨‍🍳 **Chef Section** — Introduces the restaurant's chefs.
- 📩 **Contact Form** — Provides a section for customer inquiries.
- 🎨 **CSS Animations** — Adds smooth visual transitions.
- 🖱️ **Hover Effects** — Enhances buttons, cards, and other interactive elements.
- 📐 **Modern Layouts** — Uses Flexbox and CSS Grid for structured layouts.

## 🚀 Getting Started

Run the project locally in a few simple steps.

### 1. Clone the Repository

```bash
git clone https://github.com/Snehabelure419/restaurant-website.git
```

### 2. Navigate to the Project Folder

```bash
cd restaurant-website
```

### 3. Open the Website

Open `index.html` in your browser, or open the project in Visual Studio Code and use the Live Server extension.

No additional package installation is required for this HTML and CSS project.
